# Little English Stories

A first frontend MVP for learning English through short stories.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy

Push this repository to GitHub and import it into Vercel.

## Current MVP

- Story library
- Story reader
- Sentence-by-sentence navigation
- Browser speech synthesis
- Clickable vocabulary
- Vocabulary detail popup
- Vocabulary page
- Responsive layout
